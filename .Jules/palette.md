## 2026-08-26 - Add focus states and aria labels to unstyled native HTML buttons
**Learning:** Native `<button>` elements in this app require explicit `focus-visible` utility classes (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-indigo-500 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-950`) to support keyboard navigation accessibly, since they don't inherit unified component styling. Additionally, ARIA labels for buttons containing primarily visually rendered text should incorporate that visible text to conform with WCAG 2.5.3.
**Action:** When working on navigation buttons and unstyled components, verify tab focus behaviors manually and prepend visible textual branding (e.g., config.appName) to aria labels if overriding name resolution.
