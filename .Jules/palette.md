## 2026-09-11 - Accessible Icon-only Grouped Statistics\n**Learning:** When grouping SVG icons with numerical values, adding `title` to the wrapper and visually hidden `sr-only` text provides context for screen reader users, while `aria-hidden='true'` on the SVG prevents redundant reading.\n**Action:** Apply this pattern consistently across all statistical displays (like player counts, scores, and active times) where icons represent meaning.
