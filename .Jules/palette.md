## 2024-05-15 - Missing Focus Rings on Buttons\n**Learning:** Found some `<button>` and `<a>` elements in the app that are missing the standard focus ring classes for keyboard accessibility. This makes keyboard navigation difficult for screen reader and keyboard-only users.\n**Action:** Add `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-indigo-500 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-950` (or slate-900 depending on background) to interactive elements that are lacking them, such as the back buttons in `apps/web/app/room/create/page.tsx`.
