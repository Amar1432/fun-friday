## 2026-07-31 - Immediate Feedback for Clipboard Actions

**Learning:** Users often lack confidence when clicking 'Copy' buttons if there is no immediate visual change, especially in flows where they are automatically redirected shortly after (e.g., room creation). A simple text/color change confirming the action reduces anxiety and repeat clicks.
**Action:** Always provide inline visual feedback (e.g., 'Copied!' and a checkmark) for clipboard actions, keeping it visible for 2-3 seconds before reverting to the default state.
